## 使用方法

每天留出投递与算法练习时间。技术复习按“先看问题 → 自己口述 → 阅读答案 → 用项目例子复述”进行。每学完一篇，至少回答笔记末尾的问题。项目表达优先使用自己确实参与、能举证的工作；不要把源码、构建、开发库验证说成生产上线。

本仓库已有 `MyStdudy/MySQL/` 基础笔记；[[03-MySQL查询优化与事务]] 聚焦面试中的诊断与优化，不重复 SQL 语法入门。Citic 实习系统主要用 Oracle，MySQL 的执行计划与索引细节要在 MySQL 环境单独理解，不能声称项目用了 MySQL。
